# UltraDex Gothic OS (Royal Edition)

An immersive gothic RPG productivity and life-tracking OS built with React, Tailwind CSS, and Capacitor.

## 🚀 Building APK via GitHub Actions

1. Create a new repository on GitHub.
2. Unzip this project and push all files to your GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
   git push -u origin main
   ```
3. Go to your repository on GitHub and click on the **Actions** tab.
4. You will see the **Build Android APK** workflow running automatically.
5. Once the build completes (usually takes 2-3 minutes), click on the workflow run, scroll down to **Artifacts**, and download `app-debug.apk` to install on your Android device!
